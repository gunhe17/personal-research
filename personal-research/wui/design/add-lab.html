인증 수단을 더하는 + 버튼을 어디에 둘지 비교합니다. 목록은 같습니다: Plan login(On), Plan login 2(Off), API key(Off). 몇몇 시안은 + 를 누른 직후 모습도 함께 보여 줍니다.

A0. 기준

지금. 목록 끝에 "+ Plan login", "+ API key" 두 줄. 종류를 바로 고르지만 목록이 늘 두 줄 길어 보이고, 수단처럼 보이기도 합니다.

A1. 섹션 제목 오른쪽 +

"TRY IN THIS ORDER" 같은 줄 오른쪽 끝에 작은 + 아이콘. 누르면 그 아래 메뉴에서 종류 선택. 목록은 수단만 남아 가장 깔끔합니다. 사이드바 폴더 머리의 + 와 같은 문법.

A2. 제목 줄의 글자 링크 둘

제목 오른쪽에 "+ Plan login · + API key" 를 작은 글자 링크로. 메뉴 없이 한 번에 고르면서 목록 밖에 있습니다.

A3. 목록 끝 "+ Add" 한 줄 → 펼침

목록 끝에 회색 "+ Add" 한 줄. 누르면 그 자리에서 두 개의 선택지 줄로 펼쳐지고, 고르면 새 수단이 그 자리에 생깁니다. 지금 모양을 한 줄로 줄인 형태.

A4. 줄 사이에 끼워 넣기

마우스를 줄 사이 경계에 올리면 가는 파란 선과 + 가 나타납니다. 누르면 그 순위 자리에 새 수단이 끼워집니다. 순서까지 한 번에 정하지만 처음엔 찾기 어렵습니다.

A5. 수단 세부에서 "하나 더"

수단을 펼친 세부 맨 아래에 "Add another plan login". 같은 종류를 하나 더 만들고 바로 아래에 둡니다. 아무것도 없을 때를 위해 목록이 비면 큰 빈칸 안내가 대신합니다.

A6. 사이드바 제공사 줄의 +

왼쪽 사이드바의 제공사 줄에 마우스를 올리면 + 가 나타나고, 메뉴로 그 제공사에 수단을 더합니다. 본문은 목록만. 사이드바 Space 의 "새 대화" 흐름과 같은 자리입니다.

A7. 빈 슬롯 줄

목록 끝에 점선 테두리의 빈 줄 하나: "Add a plan login or an API key" 와 안쪽의 두 알약 버튼. 무엇을 할 수 있는지 가장 분명하지만 가장 눈에 띕니다.

비교

  • 목록을 수단만으로 깔끔하게: A1, A2, A6
  • 사이드바·트리 문법과 일관: A1(폴더 머리 +), A3(목록 끝 줄), A6(사이드바)
  • 순서까지 한 번에: A4, A5
  • 처음 보는 사람에게 분명: A7, A2
