공통 규칙

  • 채운 파란 버튼은 한 화면에 하나: 지금 해야 할 일(Save, Submit, Log in 중 하나)
  • 로그인 상태는 초록 점과 한 단어(Ready / Sign in needed)
  • 기기 코드는 고정폭 큰 글씨와 Copy 버튼, 로그인 페이지는 새 탭 링크
  • API 키 칸은 API key 를 고른 제공사에만, 저장된 키는 끝 네 자리만
