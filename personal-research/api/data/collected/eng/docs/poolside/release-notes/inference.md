# Poolside Inference release notes

> Release notes for Poolside Inference deployment and runtime updates.

Poolside July 2026 is a model inference deployment bundle for supported cloud and on-premises environments.

<Update label="July 2026" description="Deployment">
  ## July 2026 inference deployment bundle

  Poolside July 2026 updates the model inference deployment bundle for supported cloud and on-premises environments.

  **Included**

  * `atlas` inference server image:
    * Host KV-cache offloading enabled by default
    * Support for downloading self-contained Hugging Face checkpoints
    * Runtime stability improvements and customer-facing bug fixes
  * SUSE Linux Enterprise Server (SLES) 16 support for on-premises deployments
  * `pool` CLI release `v1.0.8`
