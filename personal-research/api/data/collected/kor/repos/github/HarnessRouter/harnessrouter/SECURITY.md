# 보안 정책

HarnessRouter Community Edition은 여러분 자신의 공급자 키로 에이전트 CLI를 실행하며, bash, git, 파일시스템을 갖춘 로컬 작업공간에서 그 작업을 실행합니다. 어떤 인스턴스든 여러분이 부여한 자격 증명으로 코드를 실행할 수 있는 것으로 취급하고, 비밀번호를 설정하고 그 앞에 TLS를 두지 않았다면 공개 네트워크에 노출시키지 마세요.

## 취약점 신고

보안 문제는 비공개로 신고해 주세요. 취약점에 대해 공개 GitHub 이슈를 열지 마세요.

두 가지 비공개 채널이 있습니다.

- GitHub 비공개 취약점 신고: 이 저장소의 Security 탭 아래에 있는 "Report a vulnerability" 버튼을 사용하세요.
- 이메일: contact@harnessrouter.ai

재현에 필요한 정보를 포함해 주세요. 영향받는 버전이나 커밋, 환경, 재현 절차, 예상되는 영향, 가능하다면 개념 증명(proof of concept)입니다.

우리는 10 영업일 안에 신고를 확인하고, 여러분과 함께 수정과 공개 일정을 합의하며, 원한다면 수정이 배포될 때 신고자로서 여러분에게 공로를 표시하는 것을 목표로 합니다.

## 적용 범위

범위 안: 이 저장소의 게이트웨이, 러너, 콘솔, 어댑터, 그리고 프로토콜 구현.

범위 밖: 에이전트 CLI 자체(Codex, Claude Code, Hermes)는 최초 실행 시 각자의 라이선스와 각자의 보안 연락처에 따라 설치되므로 제외됩니다. 그리고 이미 침해된 호스트나 여러분이 그 인스턴스에 제공한 자격 증명을 필요로 하는 문제도 제외됩니다.
