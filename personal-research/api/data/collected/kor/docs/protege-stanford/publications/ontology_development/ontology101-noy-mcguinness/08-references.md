## 각주 (Footnotes) 번역

**[1]** 클래스 이름은 대문자로, 슬롯 이름은 소문자로 시작합니다. 예시 온톨로지의 모든 용어에는 typewriter 폰트를 사용합니다.

**[2]** 클래스를 일항 술어(인자가 하나인 질문)로도 볼 수 있습니다. 예: “이 객체는 와인인가?” 일항 술어(클래스)는 이항 술어(슬롯)—인자가 두 개인 질문—과 대비됩니다. 예: “이 객체의 flavor는 strong인가?” “이 객체의 flavor는 무엇인가?”

**[3]** 일부 시스템은 Instance 타입 슬롯을 별도로 선언하지 않고, value type을 클래스로만 지정합니다.

**[4]** 우리 온톨로지에서는 레드 Port만 표현했습니다. 화이트 Port도 존재하지만 매우 드뭅니다.

**[5]** 여기서는 각 해부 기관을 클래스로 둡니다. “John’s 1st left rib”에 대해서도 말하고 싶기 때문입니다. 실제 사람의 개별 기관은 온톨로지에서 개체로 표현됩니다.
